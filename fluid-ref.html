質量守恆
連續方程式
入出口流量平衡
積分形式
∂/∂t ∫∫∫ρ dV + ∯ρV·dA = 0
穩態 / 不可壓縮
ρ₁A₁V₁ = ρ₂A₂V₂ (可壓縮)
A₁V₁ = A₂V₂ = Q (不可壓縮)
ṁ = ρAV = ρQ
解題步驟
1
確認流況：穩態（∂/∂t = 0）？不可壓縮（ρ = const）？
2
計算各截面積 A = πD²/4
3
代入 A₁V₁ = A₂V₂ 求未知速度，或用 ṁ = ρAV 求質量流率
4
多出口：Q_in = ΣQ_out，各分支分別列式
柏努利方程式
無黏性、穩態、同流線
基本形式
p/ρg + V²/2g + z = const
─── 壓力頭 + 速度頭 + 位置頭 ───
兩點比較
p₁/ρg + V₁²/2g + z₁ = p₂/ρg + V₂²/2g + z₂
解題步驟
1
驗證適用：無黏 + 穩態 + 同流線（或旋流自由）
2
選兩個已知點（通常選已知壓力或速度處），建立方程式
3
搭配連續方程式 A₁V₁ = A₂V₂ 消去一個未知數
4
自由液面：p = pₐₜₘ，V ≈ 0（大容器）
限制：有損失、有機械功、可壓縮流 → 改用能量方程式
能量方程式
（含損失與機械功）
有損失 / 泵 / 風扇
完整形式
p₁/ρ + α₁V₁²/2 + gz₁ + ẇs
  = p₂/ρ + α₂V₂²/2 + gz₂ + hL
功率
Ẇs = ṁ · ẇs  [W]
符號說明備注
ẇs單位質量軸功泵為正，渦輪為負
α動能修正係數層流 2.0、紊流 1.05
hL損失水頭恆 ≥ 0
解題步驟
1
定截面①②，選流動方向（①→②）
2
用連續方程式求 V₁、V₂，確認 α 值
3
代入能量方程式，整理求 ẇ_s 或 h_L
4
乘以 ṁ 得功率 Ẇ_s = ṁ · ẇ_s
線動量方程式
求管道受力 / 射流衝擊
向量形式（穩態）
ΣF = ∯ρV(V·dA)
   = ṁ(V₂ − V₁) (單入單出)
解題步驟
1
畫控制體積（CV），標出所有外力：壓力、重力、管壁反力 R
2
確認流出面積正方向：流出取 +，流入取 −
3
x、y 方向分別列 ΣFₓ = ṁ(V₂ₓ − V₁ₓ)
4
管壁對流體的力 = 方程式中的 R；流體對管壁 = −R
注意：錶壓 vs 絕對壓——動量方程用錶壓即可（大氣壓項相消）
動能修正係數 α
非均勻速度剖面
定義
α = (1/A) ∫(u/V̄)³ dA  = ∫u³ dA / (V̄³ A)
常用值
層流（拋物線）：α = 2.00
紊流（近均勻）：α ≈ 1.05
均勻流（理想）：α = 1.00
解題步驟
1
判斷入出口流況 → 查對應 α 值
2
能量方程式動能項寫成 αV²/2，不可省略 α
3
層流：V̄ = u_max/2，代入時用平均速度 V̄，α = 2 補償
常見錯：誤用 u_max 代替 V̄ 計算動能，等同重複計入 α 效應
層流速度剖面
（Hagen-Poiseuille）
Re < 2300，圓管，完全發展
速度分布
u(r) = (Δp/4μL)(R² − r²)
u_max = ΔpR²/4μL
V̄ = u_max / 2
流率
Q = πR⁴Δp / 8μL  (Hagen-Poiseuille)
符號說明
R管半徑
μ動力黏度 [Pa·s]
Δp/L單位長度壓降
Darcy-Weisbach
摩擦損失
管道主要損失
主公式
hf = f · (L/D) · V²/2g
層流 f（解析解）
f = 64/Re  (Re < 2300)
紊流 f（Colebrook）
1/√f = −2 log(ε/3.7D + 2.51/Re√f)
解題步驟
1
求 Re = ρVD/μ = VD/ν，判斷層流或紊流
2
層流：f = 64/Re；紊流：查莫迪圖或用 Colebrook 疊代
3
代入 h_f = f(L/D)(V²/2g)
次要損失
彎頭、閥、入口、出口
通用公式
hm = K · V²/2g
K = 損失係數（查表）
元件K 值
尖銳入口≈ 0.5
圓滑入口≈ 0.04
突然出口= 1.0
90° 彎頭0.3 ~ 1.5
閘閥（全開）≈ 0.2
突然擴大(1 − A₁/A₂)²
解題步驟
1
列出管路中所有元件，查對應 K
2
各元件損失 h_m = KV²/2g，注意用各元件處的速度
3
總損失 h_L = h_f + Σh_m
莫迪圖
摩擦係數 f
紊流管道，查 f 值
Colebrook-White（隱式）
1/√f = −2 log[ε/(3.7D) + 2.51/(Re√f)]
Swamee-Jain（顯式近似）
f = 0.25 / [log(ε/3.7D + 5.74/Re⁰·⁹)]²
查圖步驟
1
計算 Re 和相對粗糙度 ε/D（ε：粗糙高度，鋼管 ≈ 0.046 mm）
2
Re < 2300：f = 64/Re（層流直線）
3
Re > 4000：以 Re、ε/D 定位莫迪圖上的 f，或用 Swamee-Jain 直接算
4
完全粗糙區（Re 很大）：1/√f = −2 log(ε/3.7D)，f 與 Re 無關
