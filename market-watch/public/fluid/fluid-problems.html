例題 5.1 連續方程式基本應用
已知：不可壓縮流體（水，ρ = 1000 kg/m³）穩定流過漸縮管。
截面①：直徑 D₁ = 150 mm，流速 V₁ = 3.0 m/s
截面②：直徑 D₂ = 75 mm
求：截面②的流速 V₂ 及體積流率 Q
解答
1
計算截面積：
A₁ = π(0.15)²/4 = 0.01767 m²
A₂ = π(0.075)²/4 = 0.004418 m²
2
不可壓縮穩態連續方程式：
Q = A₁V₁ = A₂V₂
Q = 0.01767 × 3.0 = 0.0530 m³/s
3
求 V₂：
V₂ = Q / A₂ = 0.0530 / 0.004418
V₂ = 12.0 m/s　　Q = 0.0530 m³/s
例題 5.4 柏努利方程式 / Venturi 流量計
已知：水平 Venturi 管，ρ = 1000 kg/m³，不計損失。
入口①：D₁ = 100 mm，壓力 p₁ = 200 kPa（表壓）
喉部②：D₂ = 50 mm，壓力 p₂ = 150 kPa（表壓）
管道水平放置，z₁ = z₂
求：流速 V₁、V₂ 及體積流率 Q
解答
1
連續方程式：A₁V₁ = A₂V₂，面積比 A₁/A₂ = (D₁/D₂)² = 4
故 V₂ = 4V₁
2
柏努利方程（水平，z₁ = z₂）：
p₁/ρ + V₁²/2 = p₂/ρ + V₂²/2
(200000 − 150000)/1000 = (V₂² − V₁²)/2 = (16V₁² − V₁²)/2 = 7.5V₁²
3
解 V₁：V₁² = 50000/(1000 × 7.5) = 6.667 → V₁ = 2.582 m/s
V₂ = 4 × 2.582 = 10.33 m/s
4
Q = A₁V₁ = π(0.1)²/4 × 2.582 = 0.02027 m³/s
V₁ = 2.58 m/s　　V₂ = 10.3 m/s　　Q = 0.0203 m³/s
例題 5.5 彎管線動量分析
已知：水流過水平 90° 彎管，ρ = 1000 kg/m³，管徑均勻 D = 100 mm，不計重力。
入口①（→x 方向）：V₁ = 5.0 m/s，表壓 p₁ = 200 kPa
出口②（→y 方向）：V₂ = 5.0 m/s，表壓 p₂ = 180 kPa
求：管壁對流體的支撐力（Rₓ, Rᵧ）及其合力
解答
1
截面積 A = π(0.1)²/4 = 0.007854 m²
質量流率 ṁ = ρAV = 1000 × 0.007854 × 5.0 = 39.27 kg/s
2
x 方向動量方程（出口無 x 分量）：
p₁A + Rₓ = ṁ(V₂ₓ − V₁ₓ) = ṁ(0 − V₁)
Rₓ = −ṁV₁ − p₁A = −39.27×5 − 200000×0.007854 = −196.4 − 1570.8 = −1767 N
3
y 方向動量方程（入口無 y 分量）：
−p₂A + Rᵧ = ṁ(V₂ᵧ − 0) = ṁV₂
Rᵧ = ṁV₂ + p₂A = 39.27×5 + 180000×0.007854 = 196.4 + 1413.7 = 1610 N
4
合力 |R| = √(1767² + 1610²) = 2393 N
方向角 θ = arctan(1610/1767) = 42.3°（第二象限）
Rₓ = −1767 N　　Rᵧ = 1610 N　　|R| = 2393 N
流體對管壁的力 = −R（牛頓第三定律）
例題 5.9 錐形噴嘴螺紋支撐力
已知：錐形噴嘴接在垂直水龍頭出口下方，水垂直向下流。ρ = 999 kg/m³
Q = 0.6 L/s = 6×10⁻⁴ m³/s
截面①（噴嘴入口，上方大口）：D₁ = 16 mm，p₁ = 464 kPa（表壓）
截面②（噴嘴出口，下方小口）：D₂ = 5 mm，p₂ = 0（大氣壓，表壓）
噴嘴質量 m = 0.1 kg，錐高 h = 30 mm
穩態、不可壓縮，流動方向垂直向下
求：固定噴嘴不動所需的螺紋支撐力 F_A（大小與方向）
解答　（z 方向，正方向向下）
1
截面積與流速：
A₁ = π(0.016)²/4 = 2.011×10⁻⁴ m²　　A₂ = π(0.005)²/4 = 1.963×10⁻⁵ m²
V₁ = Q/A₁ = 6×10⁻⁴ / 2.011×10⁻⁴ = 2.98 m/s（向下）
V₂ = Q/A₂ = 6×10⁻⁴ / 1.963×10⁻⁵ = 30.6 m/s（向下）
ṁ = ρQ = 999 × 6×10⁻⁴ = 0.599 kg/s
2
噴嘴內水的體積（截錐體）與重量：
V錐 = πh(R₁² + R₁R₂ + R₂²)/3
R₁ = 8 mm，R₂ = 2.5 mm，h = 30 mm
V錐 = π×0.03×(64+20+6.25)×10⁻⁶/3 = 2.836×10⁻⁶ m³
W水 = ρgV錐 = 999×9.81×2.836×10⁻⁶ = 0.0278 N（向下）
3
對系統（噴嘴＋內部水）列 z 方向動量方程：
W噴嘴 + W水 + p₁A₁ − p₂A₂ − F_A = ṁ(V₂ − V₁)
各項數值（向下為正）：
W噴嘴 = 0.1×9.81 = 0.981 N
p₁A₁ = 464000×2.011×10⁻⁴ = 93.3 N（向下）
p₂A₂ = 0（大氣壓）
ṁ(V₂−V₁) = 0.599×(30.6−2.98) = 0.599×27.6 = 16.5 N
4
解 F_A（支撐力向上，故取負號）：
F_A = W噴嘴 + W水 + p₁A₁ − ṁ(V₂−V₁)
F_A = 0.981 + 0.028 + 93.3 − 16.5 = 77.8 N
F_A = 77.8 N　（向上，螺紋受拉力，防止噴嘴被水壓吹落）
壓力項 p₁A₁ = 93.3 N 是主要貢獻，動量變化項反而減少所需支撐力（水加速向下，協助「推」噴嘴向下）
例題 5.11 可壓縮流噴嘴推力
已知：空氣流過收縮噴嘴，R = 287 J/(kg·K)，忽略重力。
截面①（入口）：p₁ = 888 kPa（絕壓）、T₁ = 300 K、V₁ = 305 m/s
截面②（出口）：p₂ = 128 kPa（絕壓）、T₂ = 252 K
出口面積 A₂ = 1.00×10⁻² m²，入口面積 A₁ = 1.34×10⁻² m²
求：噴嘴的軸向推力（管壁對流體的力）
解答
1
由理想氣體方程求密度：
ρᵢ = pᵢ / (R Tᵢ)
ρ₁ = 888000 / (287 × 300) = 10.31 kg/m³
ρ₂ = 128000 / (287 × 252) = 1.770 kg/m³
2
連續方程式求 V₂：
ρ₁A₁V₁ = ρ₂A₂V₂
V₂ = ρ₁A₁V₁ / (ρ₂A₂) = 10.31×1.34×10⁻²×305 / (1.770×1.00×10⁻²) = 238 m/s
3
質量流率： ṁ = ρ₁A₁V₁ = 10.31 × 1.34×10⁻² × 305 = 42.14 kg/s
4
x 方向動量方程（含邊界壓力）：
p₁A₁ + Rₓ − p₂A₂ = ṁ(V₂ − V₁)
Rₓ = ṁ(V₂−V₁) + p₂A₂ − p₁A₁
Rₓ = 42.14(238−305) + 128000×0.01 − 888000×0.0134
　　= −2823 + 1280 − 11899 = −13442 N ≈ −13.4 kN
推力 Rₓ ≈ −13.4 kN（負號表示管壁對流體向左施力）
可壓縮流須用各截面的實際密度，不可假設 ρ = const
例題 5.12 旋轉控制體積 — 角動量方程式
已知：旋轉灑水頭（Sprinkler），水從中心流入，從兩側噴嘴噴出。
ṁ（總質量流率）= 0.10 kg/s，ρ = 1000 kg/m³
噴嘴距旋轉中心 r = 0.15 m，噴嘴口截面積 a = 1.5×10⁻⁴ m²
噴嘴相對於臂的出口方向：與切線夾角 β = 0°（切向噴出）
旋轉角速度 ω = 30 rad/s（穩態旋轉）
求：所需抵抗力矩 T（軸承摩擦或外加阻力）
解答
1
每個噴嘴的質量流率：ṁ/臂 = 0.05 kg/s
相對於臂的噴射速度：W₂ = ṁ/(2ρa) = 0.05/(1000×1.5×10⁻⁴) = 0.333 m/s
（乘以 2 臂，每臂 ṁ/2 = 0.05 kg/s）
2
絕對切線速度（出口）：
V_θ2 = r·ω − W₂ = 0.15×30 − 0.333 = 4.5 − 0.333 = 4.167 m/s
（噴嘴噴出方向與旋轉方向相反，故取負號再轉換）
3
入口角動量 ≈ 0（水從中心流入，r₁ = 0）
角動量方程（Euler 渦輪方程）：
T = ṁ(r₂V_θ2 − r₁V_θ1) = ṁ · r₂ · V_θ2
T = 0.10 × 0.15 × 4.167 = 0.0625 N·m
4
軸功率： Ẇ = ω · T = 30 × 0.0625 = 1.875 W
T = 0.0625 N·m　　Ẇ = 1.875 W
例題 5.13 動量修正係數 β 的應用
已知：水流過水平直管，完全發展層流（拋物線速度分布）。
管半徑 R，平均速度 V̄，β₁（入口）= β₂（出口）= 4/3（層流）
截面①→②水平，直徑相同，壓力差 Δp = p₁ − p₂ 已知
求：說明 β 對動量方程的修正效果，並寫出含 β 的完整動量方程
解答
1
β 的定義（動量修正係數）：
β = (1/A)∫(u/V̄)² dA
均勻流：β = 1.0；層流拋物線：β = 4/3；紊流近似：β ≈ 1.02
2
無修正時動量方程（假設均勻流）：
ΔpA = ṁ(V₂ − V₁)
3
含 β 修正的動量方程：
ΔpA = ṁ(β₂V₂ − β₁V₁)
直徑相同（V₁ = V₂ = V̄）：ΔpA = ṁ · V̄(β₂ − β₁)
若兩端都是層流（β₁ = β₂ = 4/3）：ΔpA = 0
→ 表示均勻截面層流，壓力差全部克服摩擦力（動量通量不變）
4
與 α 的比較：
α 用於能量方程（V² 項），層流 = 2.00
β 用於動量方程（V 項），層流 = 4/3 ≈ 1.33
層流 β = 4/3　　紊流 β ≈ 1.02　　均勻流 β = 1
例題 5.14 移動控制體積 — 射流衝擊移動葉片
已知：水射流（ρ = 1000 kg/m³）水平射出，速度 V_jet = 20 m/s，噴嘴面積 A = 5×10⁻³ m²。
一移動葉片以速度 V_b = 8 m/s 沿射流方向移動（逃離方向）。
葉片將射流偏轉 θ = 180°（U 形葉片，完全反向）。
不計重力，流動對稱。
求：射流對葉片的作用力 F，以及葉片獲得的功率
解答
1
以移動 CV（隨葉片移動）分析，求相對速度：
W₁ = V_jet − V_b = 20 − 8 = 12 m/s（入射相對速度）
2
穿越 CV 的質量流率（用相對速度）： ṁ_rel = ρAW₁ = 1000 × 5×10⁻³ × 12 = 60 kg/s
3
偏轉 180°，出口相對速度 W₂ = W₁ = 12 m/s（反向，不計損失）
移動 CV 的動量方程（x 方向）：
Rₓ = ṁ_rel(W₂ₓ − W₁ₓ) = ṁ_rel(−W₁ − W₁) = −2ṁ_rel·W₁
Rₓ = −2 × 60 × 12 = −1440 N
流體對葉片的力 = +1440 N（推力方向與射流同向）
4
葉片獲得的功率： Ẇ = F × V_b = 1440 × 8 = 11520 W = 11.52 kW
F = 1440 N　　Ẇ = 11.52 kW
移動 CV 分析關鍵：ṁ_rel 和動量方程均使用相對速度 W，而非絕對速度 V
例題 5.16 自由射流衝擊固定平板
已知：水射流（ρ = 1000 kg/m³）以 V = 15 m/s 垂直衝擊固定水平板。
噴嘴直徑 D = 30 mm，衝擊後水沿板面向四周擴散。
忽略重力和摩擦，衝擊前後速度大小不變（Bernoulli 沿板面成立）。
求：射流對平板的衝擊力 F
解答
1
噴嘴面積：A = π(0.03)²/4 = 7.069×10⁻⁴ m²
質量流率：ṁ = ρAV = 1000 × 7.069×10⁻⁴ × 15 = 10.60 kg/s
2
取 CV 包住衝擊區，入口為射流（垂直向下），出口沿板面（水平），無垂直分量流出。
垂直（y）方向動量方程：
F − 0 = ṁ(0 − (−V)) = ṁV
出口沿水平面，垂直動量通量為 0；入口射流速度 −V（向下）
3
F = ṁV = 10.60 × 15 = 159 N（板對流體向上，流體對板向下）
衝擊力 F = 159 N（向下）
例題 5.22 風扇（渦輪）有效功率與切割效率
已知：一個風扇驅動空氣流動（ρ = 1.23 kg/m³），已知條件：
風扇入口：D₁ = 0.40 m，V₁ = 12 m/s，p₁ = 0（表壓）
風扇出口：D₂ = 0.40 m，V₂ = 12 m/s（面積相同），p₂ = 1.2×10² Pa（表壓）
水平配置（z₁ = z₂），實際消耗電功率 Ẇ_電 = 200 W
使用動能修正係數 α₁ = α₂ = 1.05（紊流）
求：風扇對流體的有效軸功率 Ẇ_shaft 及效率 η
解答
1
體積流率與質量流率： A = π(0.4)²/4 = 0.1257 m²
Q = AV = 0.1257 × 12 = 1.508 m³/s
ṁ = ρQ = 1.23 × 1.508 = 1.855 kg/s
2
能量方程式（V₁=V₂，z₁=z₂，α₁=α₂，動能項相消）：
ẇ_shaft = Δp/ρ = 120/1.23 = 97.56 J/kg
3
有效軸功率： Ẇ_shaft = ṁ · ẇ_shaft = 1.855 × 97.56 = 181 W
4
機械效率：
η = Ẇ_shaft / Ẇ_電 = 181 / 200 = 0.905
Ẇ_shaft = 181 W　　η = 90.5%
若題目給的是渦輪（輸出）：η = Ẇ_出 / Ẇ_流體，方向相反
例題 5.23 水頭損失與功率損失
已知：水（ρ = 1000 kg/m³，ν = 1×10⁻⁶ m²/s）由水塔流經管道至噴口。
上下游自由液面高差 h₀ = 9 m（有效水頭）
管道：D = 50 mm，L = 100 m，f = 0.02（已知）
噴口位於下游（p = pₐₜₘ，V₂ ≈ 出流速度），入口損失係數 K_入 = 0.5，出口不計（開放）
z₁（水塔液面）− z₂（噴口）= 9 m，p₁ = p₂ = pₐₜₘ
求：流量 Q 及管道水頭損失 h_L
解答
1
能量方程（水塔液面①→噴口②，無泵，大容器 V₁ ≈ 0）：
h₀ = V₂²/2g + h_L = V₂²/2g + [f(L/D) + K_入]·V₂²/2g
= V₂²/2g · [1 + f(L/D) + K_入]
2
代入數值： f·L/D = 0.02 × 100/0.05 = 40
總係數 = 1 + 40 + 0.5 = 41.5
V₂² = 2g·h₀/41.5 = 2×9.81×9/41.5 = 4.262 m²/s²
V₂ = 2.065 m/s
3
流量： A = π(0.05)²/4 = 1.963×10⁻³ m²
Q = AV₂ = 1.963×10⁻³ × 2.065 = 4.05×10⁻³ m³/s
4
水頭損失： h_L = h₀ − V₂²/2g = 9 − 4.262/(2×9.81) = 9 − 0.217 = 8.78 m
功率損失：Ẇ_損 = ρgQh_L = 1000×9.81×4.05×10⁻³×8.78 = 348 W
Q = 4.05×10⁻³ m³/s　　h_L = 8.78 m　　Ẇ_損 = 348 W
例題 5.24 非均勻速度曲線效應（動能修正係數 α）
已知：風扇驅動空氣流過圓管，ρ = 1.23 kg/m³。
截面①（入口）：D₁ = 0.30 m，完全發展層流 → α₁ = 2.00
截面②（出口）：D₂ = 0.20 m，紊流 → α₂ = 1.05
壓力差 p₂ − p₁ = 500 Pa（表壓差），質量流率 ṁ = 0.500 kg/s
管道水平，不計損失（h_L = 0）
求：風扇所需軸功率 Ẇ_shaft
解答
1
各截面平均速度： A₁ = π(0.3)²/4 = 0.07069 m²　→　V₁ = ṁ/(ρA₁) = 0.500/(1.23×0.07069) = 5.75 m/s
A₂ = π(0.2)²/4 = 0.03142 m²　→　V₂ = ṁ/(ρA₂) = 0.500/(1.23×0.03142) = 12.94 m/s
2
能量方程（含 α 修正，水平，h_L = 0）：
ẇ_shaft = (p₂−p₁)/ρ + α₂V₂²/2 − α₁V₁²/2
= 500/1.23 + 1.05×(12.94)²/2 − 2.00×(5.75)²/2
= 406.5 + 87.86 − 33.06 = 461.3 J/kg
3
軸功率：
Ẇ_shaft = ṁ · ẇ_shaft = 0.500 × 461.3 = 230.7 W
4
對比不考慮 α（α₁ = α₂ = 1）：
ẇ_shaft = 406.5 + (12.94)²/2 − (5.75)²/2 = 406.5 + 83.74 − 16.53 = 473.7 J/kg
差異來自 α₁ 層流項：2.00 vs 1.00 → 對結果影響顯著
Ẇ_shaft = 231 W　（若忽略 α 修正則得 237 W，高估約 2.5%）
常見錯誤：令 α = 1 略去修正，層流入口誤差可達 100%（α₁ 從 2 變 1）
