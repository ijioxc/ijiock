質量守恆
連續方程式
入出口流量平衡
積分形式
∂/∂t ∫∫∫ρ dV + ∯ρV·dA = 0
穩態 / 不可壓縮
ρ₁A₁V₁ = ρ₂A₂V₂ (可壓縮)
A₁V₁ = A₂V₂ = Q (不可壓縮)
ṁ = ρAV = ρQ
解題步驟
1
確認流況：穩態（∂/∂t = 0）？不可壓縮（ρ = const）？
2
計算各截面積 A = πD²/4
3
代入 A₁V₁ = A₂V₂ 求未知速度，或用 ṁ = ρAV 求質量流率
4
多出口：Q_in = ΣQ_out，各分支分別列式
柏努利方程式
無黏性、穩態、同流線
基本形式
p/ρg + V²/2g + z = const
─── 壓力頭 + 速度頭 + 位置頭 ───
兩點比較
p₁/ρg + V₁²/2g + z₁ = p₂/ρg + V₂²/2g + z₂
解題步驟
1
驗證適用：無黏 + 穩態 + 同流線（或旋流自由）
2
選兩個已知點（通常選已知壓力或速度處），建立方程式
3
搭配連續方程式 A₁V₁ = A₂V₂ 消去一個未知數
4
自由液面：p = pₐₜₘ，V ≈ 0（大容器）
限制：有損失、有機械功、可壓縮流 → 改用能量方程式
能量方程式
（含損失與機械功）
有損失 / 泵 / 風扇
完整形式
p₁/ρ + α₁V₁²/2 + gz₁ + ẇs
  = p₂/ρ + α₂V₂²/2 + gz₂ + hL
功率
Ẇs = ṁ · ẇs  [W]
符號說明備注
ẇs單位質量軸功泵為正，渦輪為負
α動能修正係數層流 2.0、紊流 1.05
hL損失水頭恆 ≥ 0
解題步驟
1
定截面①②，選流動方向（①→②）
2
用連續方程式求 V₁、V₂，確認 α 值
3
代入能量方程式，整理求 ẇ_s 或 h_L
4
乘以 ṁ 得功率 Ẇ_s = ṁ · ẇ_s
線動量方程式
求管道受力 / 射流衝擊
向量形式（穩態）
ΣF = ∯ρV(V·dA)
   = ṁ(V₂ − V₁) (單入單出)
解題步驟
1
畫控制體積（CV），標出所有外力：壓力、重力、管壁反力 R
2
確認流出面積正方向：流出取 +，流入取 −
3
x、y 方向分別列 ΣFₓ = ṁ(V₂ₓ − V₁ₓ)
4
管壁對流體的力 = 方程式中的 R；流體對管壁 = −R
注意：錶壓 vs 絕對壓——動量方程用錶壓即可（大氣壓項相消）
動能修正係數 α
非均勻速度剖面
定義
α = (1/A) ∫(u/V̄)³ dA  = ∫u³ dA / (V̄³ A)
常用值
層流（拋物線）：α = 2.00
紊流（近均勻）：α ≈ 1.05
均勻流（理想）：α = 1.00
解題步驟
1
判斷入出口流況 → 查對應 α 值
2
能量方程式動能項寫成 αV²/2，不可省略 α
3
層流：V̄ = u_max/2，代入時用平均速度 V̄，α = 2 補償
常見錯：誤用 u_max 代替 V̄ 計算動能，等同重複計入 α 效應

V̄ = u_max / 2

Darcy-Weisbach
摩擦損失
管道主要損失
主公式
hf = f · (L/D) · V²/2g
層流 f（解析解）
f = 64/Re  (Re < 2300)
紊流 f（Colebrook）
1/√f = −2 log(ε/3.7D + 2.51/Re√f)
解題步驟
1
求 Re = ρVD/μ = VD/ν，判斷層流或紊流
2
層流：f = 64/Re；紊流：查莫迪圖或用 Colebrook 疊代
3
代入 h_f = f(L/D)(V²/2g)
次要損失
彎頭、閥、入口、出口
通用公式
hm = K · V²/2g
K = 損失係數（查表）
元件K 值
尖銳入口≈ 0.5
圓滑入口≈ 0.04
突然出口= 1.0
90° 彎頭0.3 ~ 1.5
閘閥（全開）≈ 0.2
突然擴大(1 − A₁/A₂)²
解題步驟
1
列出管路中所有元件，查對應 K
2
各元件損失 h_m = KV²/2g，注意用各元件處的速度
3
總損失 h_L = h_f + Σh_m
莫迪圖
摩擦係數 f
紊流管道，查 f 值
Colebrook-White（隱式）
1/√f = −2 log[ε/(3.7D) + 2.51/(Re√f)]
Swamee-Jain（顯式近似）
f = 0.25 / [log(ε/3.7D + 5.74/Re⁰·⁹)]²
查圖步驟
1
計算 Re 和相對粗糙度 ε/D（ε：粗糙高度，鋼管 ≈ 0.046 mm）
2
Re < 2300：f = 64/Re（層流直線）
3
Re > 4000：以 Re、ε/D 定位莫迪圖上的 f，或用 Swamee-Jain 直接算
4
完全粗糙區（Re 很大）：1/√f = −2 log(ε/3.7D)，f 與 Re 無關

動量修正係數 β
例 5.13 型：非均勻剖面動量
定義
β = (1/A)∫(u/V̄)² dA = ∫u² dA / (V̄² A)
常用值
層流（拋物線）：β = 4/3 ≈ 1.33
紊流（近均勻）：β ≈ 1.02
均勻流：β = 1.00
動量方程修正
ΣF = β₂ṁV₂ − β₁ṁV₁ (單入單出)
與 α 的區別
α
動能修正係數，用在能量方程式的 V²/2 項，層流 = 2.00
β
動量修正係數，用在動量方程式的 V 項，層流 = 4/3 ≈ 1.33
記憶法：α > β > 1，且層流偏差遠大於紊流；紊流常省略（令 β = 1）
移動控制體積
動量方程式
例 5.14 型：CV 以速度 V_CV 移動
相對速度
W = V − VCV (流體相對 CV 的速度)
移動CV動量方程（穩態相對流）
ΣF = ṁrel(W₂ − W₁)
ṁrel = ρA|W| (用相對速度計算)
解題步驟
1
定義 CV 速度 V_CV（若等速移動，相對流為穩態）
2
計算入出口相對速度 W = V_流體 − V_CV
3
相對流質量流率 ṁ_rel = ρA|W₁|（以入口計）
4
代入 ΣF = ṁ_rel(W₂ − W₁)，求 CV 受力或加速度
關鍵：移動CV中連續方程與動量方程均使用相對速度 W，不是絕對速度 V
渦輪／泵
有效功率與效率
例 5.22 型：求 η 或實際功率
效率定義
η = Ẇshaft,實際 / Ẇshaft,理想
渦輪：η = Ẇout / (ṁ·Δhfluid)
泵　：η = ṁ·Δhfluid / Ẇin
能量方程（含 η）
Ẇshaft,理想 = ṁ[Δp/ρ + α₂V₂²/2 − α₁V₁²/2 + gΔz]
Ẇshaft,實際 = η · Ẇ理想 (渦輪)
解題步驟
1
用能量方程式求理想軸功率（不計損失，或損失已含在 h_L 中）
2
渦輪：Ẇ_out = η · ṁ · ẇ_s,理想
3
泵：Ẇ_in = ṁ · ẇ_s,理想 / η
4
功率差 = 損失：Ẇ_損失 = (1−η) · Ẇ_理想
已知功率
求流量與水頭損失
例 5.23 型：給 Ẇ 或 H，求 Q、h_L
能量方程 + 連續 聯立
p₁/ρg + V₁²/2g + z₁ = p₂/ρg + V₂²/2g + z₂ + hL
hL = f(L/D)V²/2g + ΣKV²/2g
功率關係
Ẇ = ρgQH = ṁgH
H = (p₁−p₂)/ρg + z₁−z₂ + (V₁²−V₂²)/2g
解題步驟
1
由 Q = Ẇ / (ρgH) 或能量方程求 Q（H 為有效水頭）
2
由 Q 求截面速度 V = Q/A
3
計算 Re → 求 f → 代入 Darcy 求 h_f
4
將 h_L 代回能量方程驗算，或直接由能量方程差值得 h_L
常見題型：給泵功率 Ẇ 和管路幾何，解出流量 Q，再回頭求損失 h_L（需疊代若 f 未知）

例 5.9 型：多出口求接頭力
穩態線動量（多出口）
ΣF = Σ出ṁᵢVᵢ − Σ入ṁⱼVⱼ
質量：ṁ₁ = ṁ₂ + ṁ₃
x / y 方向展開
ΣFₓ = ṁ₂V₂cosθ₂ + ṁ₃V₃cosθ₃ − ṁ₁V₁
ΣFᵧ = ṁ₂V₂sinθ₂ − ṁ₃V₃sinθ₃
解題步驟
1
畫 CV 包住接頭，標入口①、出口②③及角度 θ
2

3
外力包含：各截面錶壓力 pᵢAᵢ、管壁反力 Rₓ、Rᵧ（未知）、重力
4
x、y 分別列動量方程，解出 Rₓ、Rᵧ，接頭受流體力 = −R
符號規則：流出 CV 的動量通量取 +，流入取 −；壓力項以錶壓計（大氣項相消）

噴嘴動量方程式
例 5.11 型：氣體噴嘴求力
動量方程（含壓力邊界）
ΣFₓ = ṁ(V₂ − V₁) + (p₂−pₐₜₘ)A₂ − (p₁−pₐₜₘ)A₁
或直接用絕對壓 + 加入大氣壓在 CV 外壁的貢獻
理想氣體密度
ρ = p / (RT)  [kg/m³]
ṁ = ρAV = pAV/(RT)
符號說明單位
R氣體常數（空氣 287）J/(kg·K)
T絕對溫度K
p絕對壓力Pa
解題步驟
1
以理想氣體 ρ = p/RT 求兩截面密度
2
用連續方程式 ρ₁A₁V₁ = ρ₂A₂V₂ 確認 ṁ
3
動量方程：R + p₁A₁ − p₂A₂ = ṁ(V₂ − V₁)（同方向）
4
解 R 即為管壁對流體的力；注意壓力用絕對壓，CV 外壁大氣壓需納入
與不可壓縮差異：ρ 隨截面變化，必須用 ρ = p/RT；速度高時需考慮馬赫數是否超音速
旋轉控制體積
角動量方程式
例 5.12 型：渦輪 / 泵葉輪
Euler 渦輪方程式
Tshaft = ṁ(r₂Vθ2 − r₁Vθ1)
Ẇshaft = ω·T = ṁ·ω(r₂Vθ2 − r₁Vθ1)
角動量方程（積分）
ΣT = d/dt∫r×ρV dV + ∯(r×V)ρV·dA
穩態：ΣT = ṁ(r₂Vθ2 − r₁Vθ1)
符號說明
r₁, r₂入、出口半徑
Vθ切線方向速度分量
ω旋轉角速度 [rad/s]
解題步驟
1
確認旋轉軸，定義 r（半徑）與 Vθ（切線速度）正方向
2
分解入出口速度：V_θ = V·cosα（α 為速度與半徑夾角）
3
代入 T = ṁ(r₂V_θ2 − r₁V_θ1)，注意旋轉方向正負
4
功率 Ẇ = ωT；渦輪（做功）T 與 ω 同向，泵（輸入功）相反
正負規則：Vθ2 與 ω 同方向 → 渦輪輸出正功；若相反 → 為泵（輸入功）
